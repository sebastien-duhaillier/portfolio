Extension Chrome

Politique de confidentialité

La Bonne Feuille permet d’expérimenter temporairement des styles CSS dans le navigateur, sans compte, sans publicité et sans serveur applicatif.

Dernière mise à jour : 18 novembre 2026

Présentation

La Bonne Feuille est une extension Chrome permettant de sélectionner un élément d’une page web, d’expérimenter temporairement des styles CSS et d’exporter le résultat.

L’extension fonctionne localement dans le navigateur. Elle ne nécessite aucun compte et ne communique avec aucun serveur exploité par le développeur.

Données utilisées

Lorsque l’utilisateur ouvre volontairement l’extension sur un onglet, La Bonne Feuille accède temporairement aux informations strictement nécessaires à son fonctionnement :

  • l’adresse de la page active, sans paramètres ni fragment ;
  • le titre de la page, affiché temporairement dans le panneau ;
  • la balise, le sélecteur CSS et certaines propriétés visuelles de l’élément sélectionné ;
  • le CSS saisi, généré ou importé par l’utilisateur.

La Bonne Feuille ne collecte pas le texte de l’élément sélectionné.

Stockage local

Les sessions enregistrées contiennent uniquement :

  • l’identité de la page composée de son origine et de son chemin, sans paramètres ni fragment ;
  • le CSS appliqué ;
  • les propriétés CSS structurées par sélecteur ;
  • la date d’enregistrement.

Ces informations sont conservées dans chrome.storage.local, sur l’appareil de l’utilisateur. Elles ne sont ni synchronisées avec un compte distant ni transmises au développeur.

L’utilisateur peut supprimer la session de la page actuelle ou toutes les sessions locales depuis l’extension. La désinstallation supprime également son stockage local.

Importation et exportation

L’utilisateur peut exporter son CSS ou une session JSON sur son appareil, puis les importer ultérieurement. Ces fichiers restent sous son contrôle.

Pour limiter les chargements distants involontaires, La Bonne Feuille refuse les règles @import et les URL externes présentes dans le CSS appliqué.

Transmission, partage et utilisation limitée

La Bonne Feuille :

  • ne transmet aucune donnée à un serveur externe ;
  • n’utilise aucun outil d’analyse ou de suivi ;
  • n’affiche aucune publicité ;
  • ne vend, ne loue et ne partage aucune donnée utilisateur ;
  • n’utilise aucune donnée pour le profilage ou le marketing.

L’utilisation des informations reçues des API Chrome respecte la politique relative aux données utilisateur du Chrome Web Store, y compris les exigences d’utilisation limitée. Ces informations servent uniquement à fournir les fonctions visibles décrites sur cette page.

Permissions Chrome

  • activeTab : accès temporaire à l’onglet sur lequel l’utilisateur déclenche l’extension ;
  • scripting : injection locale de l’inspecteur visuel et des styles temporaires ;
  • storage : enregistrement local des sessions CSS choisies par l’utilisateur ;
  • sidePanel : affichage de l’interface dans le panneau latéral de Chrome.

L’extension ne demande aucune autorisation permanente couvrant tous les sites et n’est pas disponible en navigation privée.

Contact

Pour toute question concernant l’extension ou cette politique, contactez le développeur depuis la rubrique Contact du portfolio.

Évolution de cette politique

Cette politique pourra être mise à jour si le fonctionnement de l’extension évolue. La date affichée en haut de la page sera alors modifiée.
